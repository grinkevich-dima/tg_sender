# Документация TG Sender

TG Sender — командная веб-панель для аутрича в Telegram: каждый менеджер пишет лидам **от своего личного аккаунта**.
В панели есть общая база лидов с закреплением за аккаунтами, кампании по шаблонам и из Excel, прогрев и лимиты для каждого аккаунта, ответы и отчёты.

## Коротко о главном

- **Работает от аккаунтов команды** через официальный API Telegram (MTProto, библиотека Telethon). Получатели видят сообщение от конкретного менеджера, а не от бота.
- **Один лид — один аккаунт.** Лид закрепляется за аккаунтом, и коллеги ему не пишут; отписка действует на всю команду.
- **Данные у вас:** база Postgres и файлы сессий в `data/`. Файл сессии даёт полный доступ к аккаунту — никому его не передавайте.
- **Отправка идёт медленно, и это сделано специально.** Лимит в день растёт постепенно, между сообщениями выдерживаются случайные паузы, отправка идёт только в рабочие часы. Если Telegram ставит ограничение, панель сама встаёт на паузу.
- **Отчёт по каждому сообщению:** доставлено, прочитано, ответил или ошибка с причиной.
