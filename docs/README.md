# Документация TG Sender

TG Sender — веб-панель для рассылки сообщений по своим контактам в Telegram от **личного аккаунта**.
В панели есть шаблоны, списки обращений из Excel, прогрев аккаунта и отчёты о доставке и прочтении.

## Коротко о главном

- **Работает от вашего аккаунта** через официальный API Telegram (MTProto, библиотека Telethon). Получатели видят сообщение от вас, а не от бота.
- **Всё хранится локально** в папке `data/`: база SQLite и файл сессии. Файл сессии даёт полный доступ к аккаунту — никому его не передавайте.
- **Отправка идёт медленно, и это сделано специально.** Лимит в день растёт постепенно, между сообщениями выдерживаются случайные паузы, отправка идёт только в рабочие часы. Если Telegram ставит ограничение, панель сама встаёт на паузу.
- **Отчёт по каждому сообщению:** доставлено, прочитано, ответил или ошибка с причиной.
