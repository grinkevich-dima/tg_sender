# Формат списка xlsx

Список обращений — это файл Excel, где **каждая строка — отдельный адресат** (человек или чат) **со своим готовым текстом**.
Образец структуры — лист «Единый список».

## Как панель читает файл

1. Просматривает листы по порядку и в первых 15 строках ищет **строку заголовков**: в ней должна быть колонка ссылки и колонка «Тип» или колонка текста. Строки над заголовками (название, пояснения) пропускаются.
2. Колонки определяются **по началу названия, без учёта регистра**. Порядок колонок и лишние колонки не важны.
3. Пустые строки (без ссылки, названия, имени и текста) пропускаются.

## Колонки

| Название колонки начинается с… | Поле | Обязательно | Для чего |
|---|---|---|---|
| `Исх` (Исх. №) | номер строки | нет | показывается в таблице и отчёте |
| `Тип` | тип адресата | желательно | `Чат` / `Группа` / `Канал` → чат; `Человек` → личка; `Бот` |
| `Имя` | имя | нет | подставляется в `[Имя]` (см. ниже) |
| `Фамилия` | фамилия | нет | для отображения |
| `Название` (Название / имя в Telegram) | название | желательно | отображение; **поиск чата по названию**, если ID не подошёл |
| `Папка` (Папка / источник) | источник | нет | фильтр «Поиск» |
| `Ссылка на тему` | тема форума | для форумов | в какую тему писать |
| `Ссылка` | адресат | **да** | куда отправлять (форматы ниже) |
| `План` (План действия) | — | нет | справочно |
| `Куда` | название темы | нет | показывается как «→ Тема» |
| `Примечание` | — | нет | фильтр «Поиск» |
| `Текст №` | номер варианта | нет | если нет готового текста — текст берётся с листов «Тексты…» |
| `Обращение` / `Текст` | **текст сообщения** | **да** | отправляется как есть |
| `Статус` | статус из файла | нет | фильтр «Статус из файла»; по умолчанию исключаются «Отправлено…», «Не писать», «Только личные обращения» |
| `На ты` (На ты / вы) | форма обращения | нет | фильтр; значение `Не писать` исключается по умолчанию |
| `История` (История личного общения) | есть ли диалог | желательно | порядок очереди; сверяется с Telegram |

> Первая подходящая колонка побеждает: если есть и «Обращение (черновик)», и «Текст», текстом станет та, что левее.

## Форматы ссылок

| Ссылка | Как понимается |
|---|---|
| `https://web.telegram.org/a/#152949444` | человек с ID 152949444 |
| `https://web.telegram.org/a/#-1001234567890` | супергруппа / канал (ID с `-100`) |
| `https://web.telegram.org/a/#-4012345678` | обычная группа (ID без `-100`) |
| `https://web.telegram.org/a/#-1001234567890_29438` | тема 29438 в форуме |
| `https://t.me/username`, `@username` | по username |
| `https://t.me/c/1234567890/…` | супергруппа `-1001234567890` |

**Как получить ссылку:** откройте чат в https://web.telegram.org/a/ и скопируйте адрес из строки браузера. **Не дописывайте `-100` вручную**: у обычных групп его нет. Если ошиблись, панель попробует оба варианта и поиск по названию, но лучше сразу указать правильно.

## Темы форумов

- Тема берётся из колонки **«Ссылка на тему»** (`…#<ID чата>_<ID темы>`).
- Тема применяется, **только если ссылка на тему ведёт в тот же чат**, что и основная ссылка. Иначе при загрузке появится предупреждение, и сообщение уйдёт без темы.
- Тема `_1` — это «General»: сообщение уходит в общий поток.
- В обычные группы (не форумы) сообщение всегда уходит без темы.

## Тексты с отдельных листов

Если колонка текста пустая, но заполнен **«Текст №»**, панель ищет лист, в названии которого есть «текст» (например, «Тексты 11–20»). На листе должны быть колонки `№` и `…Текст`. Метка `[Имя]` в тексте заменяется на значение колонки «Имя».

## Статус из файла → группы фильтра

Для фильтра статус сокращается до первой части — до « · », «; », «. » или «: ».

| В файле | В фильтре |
|---|---|
| `Отправлено 28.09.2026 · партия после теста; повторно не отправлять…` | `Отправлено 28.09.2026` |
| `Не отправлено. Прямая ссылка не открыла чат…` | `Не отправлено` |
| `Не писать` | `Не писать` |

Панель **не изменяет ваш файл**: статусы отправки хранятся в панели и выгружаются в «⬇ Отчёт CSV».

## Проверьте перед загрузкой

- [ ] Имя в приветствии совпадает с получателем (частая ошибка — строку скопировали, а текст остался от другого человека).
- [ ] У чатов ссылка из web.telegram.org/a, без дописанного вручную `-100`.
- [ ] «Ссылка на тему» ведёт в тот же чат.
- [ ] Строки, которые не нужно отправлять, отмечены в «Статус» или «На ты / вы» значением `Не писать`.
- [ ] Строки, скрытые фильтром или «Скрыть» в Excel, **всё равно загружаются**. Удалите их или отметьте статусом.
