# Что нового

## 2026-10-01 — ИИ-помощник
- Раздел **«ИИ»**: общая инструкция команды, общая база знаний, **ИИ-профили** кампаний (инструкция, карточки, примеры), проверка ответа профиля.
- В инбоксе — **«✨ Предложить ответ»** (черновик по профилю кампании) и **разбор входящих** с кнопкой применить этап / отписать.
- Черновики, отправленные почти без правок, сами становятся примерами профиля.
- Модель — BitrixGPT 5.5 через Битрикс24 Вайбкод (`VIBECODE_AI_API_KEY`); подходит любой OpenAI-совместимый API.
- Миграция `010_ai`.

## 2026-10-01 — дожимы
- В кампании появилась **цепочка**: до 3 дожимов с задержкой в днях и условием («нет ответа», «прочитал, но не ответил», «не прочитал»).
- Цепочка останавливается при ответе, отписке или этапе, поставленном вручную; невыполненное условие пропускает шаг.
- Дожимы входят в дневной лимит и уходят раньше новых первых сообщений. Дневной лимит теперь считает все сообщения кампаний за день.
- Статистика по шагам на странице кампании; шаг и дата следующего дожима в строках лидов.
- Миграция `009_followups`.

## 2026-10-01 — инбокс и воронка
- Новый раздел **«Инбокс»**: диалоги с лидами, фильтры «ждут ответа» / непрочитанные / этап / сегмент, переписка с подгрузкой новых сообщений, ответ из панели от закреплённого аккаунта.
- В историю попадают сообщения, которые менеджер пишет лиду прямо в Telegram.
- **Воронка**: этапы «написали → ответил → интерес → записался → пришёл / купил», «отказ»; первые два ставятся сами; админ меняет этапы в «Правилах». Сводка — на дашборде и в сегменте.
- Заметка и «Отписать» в карточке лида; счётчик непрочитанных в меню.
- Миграция `008_inbox`.

## 2026-09-30 — поиск групп
- Новый раздел **«Поиск групп»**: поиск публичных групп по ключевым словам и месту, группы обсуждения найденных каналов, проверка списка ссылок.
- Оценка групп 0–100 (тема, живость, размер), стоп-слова, язык, дата последнего сообщения.
- Статусы найденных групп: новая / интересна / вступил / отклонена; «вступил» ставится автоматически.
- Пока идёт поиск, отправка с аккаунта стоит.
- Миграция `005_chat_search`.
- Исправлено: поиск не запускался с пустым названием (ошибка «Field required»).

## 2026-09-30 — удобнее выбирать группы
- Источники сегмента разложены по вкладкам: «Из каналов TG», «Из CSV», «Из контактов TG», «По тегу»; выбранная вкладка запоминается.
- Группы показаны таблицей с поиском по названию, числом участников, аккаунтом и ссылками: «открыть ↗» (веб-версия Telegram) и `t.me/…` у публичных групп.
- Миграция `004_dialog_username`.
- Можно отметить несколько групп сразу и загрузить их участников одним действием; кнопка «Выбрать все найденные».

## 2026-09-30 — сегменты и свои группы
- **Сегменты** — именованные списки лидов; кампания по шаблону создаётся по сегменту.
- Наполнение сегмента: **участники своих групп**, CSV, записная книжка и личные диалоги аккаунта, тег.
- Переменные шаблона `{group}` (название группы) и `{joined}` (дата вступления) у участников групп.
- Фильтр «Сегмент» в разделе «Лиды».
- Миграции `002_segments`, `003_own_groups`.

## 2026-09-30 — командная версия (этап 0)
- Postgres вместо SQLite, миграции `app/migrations/*.sql`.
- Пользователи и роли (админ, менеджер), вход по логину и паролю, сброс пароля командой `python -m app.cli`.
- Несколько аккаунтов Telegram: у каждого свои лимиты, прогрев, рабочие часы и паузы; ограничение Telegram останавливает только свой аккаунт.
- Общая база лидов с объединением дубликатов; лид закрепляется за одним аккаунтом.
- Кампании по шаблону и из xlsx на одной модели; знакомые люди достаются аккаунтам, у которых с ними есть переписка.
- Правила команды: отписка на всех, «не писать одному человеку чаще раза в N дней».
- Ответы лидов сохраняются и видны на дашборде.
