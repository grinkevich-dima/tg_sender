## 2026-09-30 — сегменты и свои группы

## 2026-09-30 — командная версия (этап 0)
- Postgres вместо SQLite, миграции `app/migrations/*.sql`.
- Пользователи и роли (админ, менеджер), вход по логину и паролю, сброс пароля командой `python -m app.cli`.
- Несколько аккаунтов Telegram: у каждого свои лимиты, прогрев, рабочие часы и паузы; ограничение Telegram останавливает только свой аккаунт.
- Общая база лидов с объединением дубликатов; лид закрепляется за одним аккаунтом.
- Кампании по шаблону и из xlsx на одной модели; знакомые люди достаются аккаунтам, у которых с ними есть переписка.
- Правила команды: отписка на всех, «не писать одному человеку чаще раза в N дней».
- Ответы лидов сохраняются и видны на дашборде.
