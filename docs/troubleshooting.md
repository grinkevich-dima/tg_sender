# Частые проблемы

## Вход

**Код не приходит.**
Код приходит **в приложение Telegram** — в служебный чат «Telegram» с синей галочкой на ваших устройствах, а не по SMS. Проверьте архив, найдите чат поиском «Login code» или «Код». Проще всего войти **по QR-коду**.

**«Returned when all available options for this type of number were already used…» (SEND_CODE_UNAVAILABLE).**
«Получить код» нажимали несколько раз подряд, и Telegram исчерпал способы доставки. Войдите по QR-коду или подождите 30–60 минут и нажмите «Получить код» **один раз**.

**Камера пишет «неверный код» при сканировании QR.**
Сканируйте в **приложении Telegram**: Настройки → Устройства → Подключить устройство, а не обычной камерой. QR обновляется каждые ~30 секунд. Держите открытой одну страницу с QR: если открыть вторую, первая перестанет работать.

**«Не заданы TG_API_ID и TG_API_HASH».**
Заполните `.env` (см. [Быстрый старт](quickstart.md)) и перезапустите контейнер: `docker compose up -d`.

**«Этот Telegram-аккаунт уже подключён в панели».**
Один аккаунт Telegram можно подключить только один раз. Найдите его в «Аккаунтах» (админ видит все) и войдите там.

**Забыли пароль от панели.** Админ меняет его в «Команде». Если забыл сам админ, на сервере выполните:
```bash
docker compose exec tg-sender python -m app.cli users                  # список логинов
docker compose exec tg-sender python -m app.cli set-password ЛОГИН     # спросит новый пароль
```

## Отправка

| Ошибка в таблице | Причина | Что делать |
|---|---|---|
| `получатель не найден: ID нет в кэше сессии…` | человек не в ваших диалогах и не найден в чатах списка | «🔎 Найти получателей»; если не помогло — у вас нет общего диалога или чата с человеком |
| `чат не найден среди ваших диалогов…` | вы не состоите в чате или ссылка неверна | проверьте ссылку (см. [формат ссылок](xlsx-format.md#форматы-ссылок)) и что вы участник; «Найти получателей» обновит список диалогов |
| `UserPrivacyRestricted` | человек запретил писать ему незнакомцам | только лично или через общий контакт |
| `UserIsBlocked` / `YouBlockedUser` | блокировка с одной из сторон | — |
| `InputUserDeactivated` / `UserDeactivated` | аккаунт удалён | — |
| `UsernameNotOccupied` / `UsernameInvalid` | такого username нет | исправьте в файле или CSV |
| `ChatWriteForbidden` / `ChatAdminRequired` / `ChatRestricted` | в чате нельзя писать (права, только админы) | — |
| `ChannelPrivate` | вас нет в приватном канале или группе | вступите в чат |
| `SlowModeWait` | в чате медленный режим | «↺» и повторить позже |
| `ChatSendPlainForbidden` | в чате запрещены текстовые сообщения | — |
| `нет текста` | пустая колонка текста | заполните текст или «Текст №» |
| `закреплён за другим аккаунтом (…)` | этому лиду уже пишет коллега | добавьте его аккаунт в кампанию или оставьте лида ему |
| `уже писали ДД.ММ (правило команды…)` | команда писала этому человеку недавно | подождите или (админ) измените срок в «Правилах» |
| `лид отписался` | ответил стоп-словом или исключён вручную | вернуть может только админ в «Лидах» |
| `прервано во время отправки…` | панель остановилась в момент отправки | проверьте переписку в Telegram; если сообщения нет — «↺» |

Строки с ошибками можно вернуть: в кампании — «↻ Повторить ошибки», в списке — «↺» в строке.

**Отправка стоит.** Посмотрите «Статус отправки» на дашборде:
- «вне рабочих часов» — ждёт начала рабочего времени;
- «дневной лимит исчерпан» — продолжит завтра (или увеличьте лимит);
- «пауза до … (ограничение Telegram)» — см. [Прогрев и лимиты](limits.md#защита-от-ограничений);
- «очередь пуста» — кампания или список не запущены: нажмите «▶ Запустить»;
- «аккаунт не авторизован» — войдите заново в «Аккаунтах»;
- «аккаунт на паузе (вручную)» — нажмите ▶ в «Аккаунтах»;
- «идёт поиск получателей» — отправка продолжится, когда поиск закончится.

Статус у каждого аккаунта свой: одна кампания может идти с одного аккаунта и стоять на другом.

**«Кампания идёт с нескольких аккаунтов — сначала нажмите „Найти получателей“».** Без снимка диалогов нельзя понять, кто из команды с кем знаком, и знакомый человек получил бы «Привет!» от незнакомого аккаунта. Нажмите «🔎 Найти получателей» и повторите.

**«Нужно войти в панель» / выкинуло на страницу входа.** Сессия истекла (14 дней), пароль сменили или пользователя отключили.

**«Запрос с чужого сайта отклонён» (403).** Панель открыта по адресу, которого нет в `ALLOWED_HOSTS`, или прокси подменяет заголовок `Host`. См. [Установка и эксплуатация](operations.md#на-сервере-247).

**Сообщение ушло не в ту тему или не в тот чат.** Проверьте «Ссылку на тему»: тема применяется, только если ссылка на неё ведёт в тот же чат. Если текст и получатель не совпадают по имени, строку скопировали без правки текста — исправьте файл.

## Поиск получателей

**«A wait of N seconds is required (caused by GetDialogsRequest)».**
Это обычная защита Telegram при загрузке тысяч диалогов. Панель сама выжидает паузы до 5 минут. Если пауза дольше, запустите поиск ещё раз позже.

**Поиск идёт долго.** При 2–3 тысячах диалогов нормально 2–3 минуты на каждый аккаунт кампании. Прогресс показан под кнопками.

## Сегменты и свои группы

**В списке нет моей группы.** Нажмите «↻ Обновить список своих групп» на странице сегмента и дождитесь «готово». В списке только группы (не каналы) выбранного аккаунта. Если группа есть только у коллеги — добавляйте участников с его аккаунта.

**«Можно брать участников только из групп».** Группы нет в сохранённом списке аккаунта. Обновите список групп.

**Добавилось меньше людей, чем в группе.** Боты и удалённые аккаунты не добавляются; уже бывшие в сегменте не считаются повторно. В больших группах Telegram может отдать не всех участников.

**«Добавлено в сегмент: 0» при повторной загрузке.** Все участники уже в сегменте — новые появятся после следующего мероприятия.

## Поиск групп

**Нашлось мало групп.** Поиск Telegram отдаёт 10–20 результатов на запрос и ищет по названию и username. Добавьте больше вариантов слов (синонимы, сленг, английские названия) и мест; проверьте списки из каталогов через «Проверить ссылки».

**«Telegram попросил подождать N сек».** Поиск ограничен по частоте. Повторите позже кнопкой **↻** у поиска — найденное сохранится.

**Активность «—».** Telegram не отдал сообщения группы без вступления (так бывает у некоторых групп). Оценка тогда не выше 10 — откройте группу по ссылке и решите сами.

**Отправка с аккаунта стоит со статусом «идёт поиск…».** Пока идёт поиск групп, аккаунт занят; отправка продолжится сама.

## Ссылки на группы

**Нет ссылки «в приложении».** У группы без username приложение открывается только через номер сообщения, а его панель узнаёт при «↻ Обновить список своих групп» (в сегменте) или при поиске. Обновите список; если в группе ещё нет сообщений, ссылки не будет — откройте её через «открыть ↗».

**«в приложении» ничего не делает.** Браузер должен знать, что ссылки `tg://` открывает Telegram: установите Telegram Desktop и при первом клике разрешите браузеру его открывать.

## Кампании из xlsx

**Загрузилось больше строк, чем ожидалось.** Панель читает все непустые строки листа, включая скрытые в Excel и строки ниже видимой области. Удалите лишние строки в файле или отфильтруйте их в панели.

**«Не нашёл лист с колонками «Тип», «Ссылка»…».** Названия колонок должны начинаться так, как описано в [Формат списка xlsx](xlsx-format.md#колонки).
