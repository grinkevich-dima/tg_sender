## Дашборд

Главная страница. Обновляется сама раз в 30 секунд.

- **Отправлено сегодня / лимит** — общий счётчик по кампаниям и спискам.
- **День прогрева** — сколько дней прошло с первой отправки (см. [Прогрев и лимиты](limits.md)).
- **Статус отправки** — чем сейчас занят фоновый отправщик: «отправка», «очередь пуста», «вне рабочих часов», «дневной лимит исчерпан», «пауза до … (ограничение Telegram)».
- **Кампании** — сводка по последним 10 кампаниям.
- **↻ Обновить статусы прочтения** — запросить у Telegram, какие сообщения прочитаны. Панель делает это и сама раз в 30 минут, а пока она запущена, прочтения приходят мгновенно.
- **Последние события** — 15 последних записей журнала.

## Вход в аккаунт

Пункт меню «🔑 Войти», после входа там отображается имя аккаунта.

| Способ | Когда использовать |
|---|---|
| **QR-код** | основной способ; не зависит от доставки кода |
| **Номер → код → пароль 2FA** | если под рукой нет телефона с Telegram |

- Код входа приходит **в приложение Telegram** (чат «Telegram» с галочкой), а не по SMS, если аккаунт открыт на других устройствах.
- Нажимайте «Получить код» **один раз**. При повторных нажатиях Telegram перестаёт отправлять коды на этот номер — тогда входите по QR.
- Сессия сохраняется в `data/account.session`, повторно входить не нужно.
- «Выйти из аккаунта» завершает сессию панели в Telegram.

## Контакты

База людей для **кампаний по шаблону**. Списки из xlsx хранят своих адресатов отдельно — см. [Списки xlsx](#списки-xlsx).

### Импорт из Telegram
- **Записная книжка Telegram** — все ваши контакты.
- **Все, с кем есть личная переписка** — собеседники из личных диалогов, без ботов и служебных аккаунтов.

Это самый надёжный способ: Telegram уже «знает» этих людей, и отправка им проходит без ошибок «не найден».

### Импорт из CSV
Разделитель `,`, `;` или Tab, кодировка UTF-8. Колонки (регистр не важен):

| Колонка | Синонимы | Пример |
|---|---|---|
| `username` | `telegram` | `ivan_petrov`, `@ivan_petrov`, `https://t.me/ivan_petrov` |
| `phone` | `телефон` | `+375291234567` |
| `user_id` | `id` | `152949444` |
| `first_name` | `name`, `имя` | `Иван` |
| `last_name` | `фамилия` | `Петров` |
| `tags` | — | `clients,vip` |
| любая другая | — | `company` → доступна в шаблоне как `{company}` |

В строке должна быть хотя бы одна из колонок `username`, `phone` или `user_id`. Дубликаты (по ID, username, телефону) обновляются, а не создаются заново. Пример — `contacts_example.csv`.

> Найти человека по телефону можно, только если он есть в вашей записной книжке. Поиск по username Telegram ограничивает — примерно сотни запросов в день.

### Действия
- **Фильтр** по тегу и поиск по имени, username, телефону.
- **исключить / вернуть** — вручную отписать контакт от всех рассылок.
- **Удаление** — всех контактов или по тегу; для подтверждения нужно ввести «да».

## Шаблоны

Текст сообщения для кампаний.

| Возможность | Синтаксис | Результат |
|---|---|---|
| Переменные | `{first_name}`, `{last_name}`, `{name}`, `{username}`, `{phone}` + колонки CSV | подставляются данные контакта |
| Спинтакс | `{Привет\|Добрый день\|Здравствуйте}` | у каждого получателя случайный вариант |
| Вложенность | `{Привет, {first_name}\|Добрый день}` | работает |
| Форматирование | `**жирный**`, `__курсив__`, `[текст](https://…)` | Markdown Telegram |

Если переменная пустая, лишние пробелы и запятые убираются: «Привет, {first_name}!» без имени превращается в «Привет!».

- В карточке шаблона есть **пример** для первого контакта базы.
- **Тест в «Избранное»** отправляет текст вам в «Избранное».
- Шаблон, который уже используется в кампании, удалить нельзя.

## Кампании

Кампания — это шаблон плюс группа контактов.

1. Укажите название, шаблон и тег (или «Все контакты»).
2. **Не отправлять тем, кто уже получил этот шаблон** — защита от повторов, включена по умолчанию.
3. **Запустить сразу** — иначе кампания останется черновиком.

Отписавшиеся контакты исключаются автоматически.

На странице кампании:
- счётчики: всего, доставлено, прочитано, ответили, ошибки, в очереди; прогресс-бар и оценка, за сколько дней уйдёт остаток при текущем лимите;
- **▶ Запустить / ⏸ Пауза / ↻ Повторить ошибки / ⬇ Отчёт CSV / Удалить**;
- таблица сообщений с фильтром по статусу (до 500 строк; полный список — в CSV).

## Списки xlsx

Готовые списки обращений, где у **каждой строки свой текст**: персональные приглашения, посты в чаты, темы форумов. Формат файла описан в [Формат списка xlsx](xlsx-format.md).

### Загрузка
«Списки xlsx» → выберите файл → «Загрузить». Панель сама находит лист и строку с заголовками. Если что-то не так, после загрузки появится предупреждение: сколько строк без текста, без ссылки, где тема указывает на другой чат.

### Найти получателей
Кнопка **🔎 «Найти получателей»**:
1. загружает все ваши диалоги. Если их тысячи, это займёт несколько минут: Telegram делает паузы, и это нормально;
2. для людей, которых нет в диалогах, загружает участников чатов из этого же списка;
3. **сверяет «Историю общения»** из файла с реальностью: есть ли с человеком личная переписка.

Нажмите её перед первой отправкой, особенно если в списке есть люди «без диалога».

### Фильтр и очередь
Блок «Фильтр и очередь» по умолчанию свёрнут. Внутри — выпадающие фильтры:

| Фильтр | Значения |
|---|---|
| Тип | Человек, Чат, Бот |
| Диалог: файл | как в колонке «История личного общения» |
| Диалог: Telegram | «Диалог есть», «Диалога нет», «не проверено» — после «Найти получателей» |
| Ты / вы | из колонки «На ты / вы» |
| Состояние | новая, в очереди, доставлено, ошибка… |
| Статус из файла | сгруппированная колонка «Статус»: «Не отправлено», «Отправлено 28.09.2026»… |
| Ещё | только с текстом; только со ссылкой; только расхождения с Telegram; порядок очереди по Telegram |
| Поиск | по папке, названию, примечанию и тексту |

**По умолчанию** выбраны новые строки с текстом и ссылкой, кроме статусов «Отправлено…», «Не писать» и «Только личные обращения».

Кнопки:
- **➕ В очередь (N)** — поставить отфильтрованные строки в очередь;
- **➕ В очередь и запустить** — то же, и сразу начать отправку.

Порядок очереди — по правилам чередования: **чат → человек с диалогом → человек без диалога → снова чат…**. Когда одна группа заканчивается, продолжаются остальные.

### Таблица строк
| Колонка | Что показывает |
|---|---|
| № | «Исх. №» из файла и позиция в очереди |
| Кому | название или имя, тема форума (→ …), «нет ссылки», если её нет |
| Тип / ты-вы | тип адресата и форма обращения |
| Диалог: файл → Telegram | сверху — из файла; снизу — «✓ …» совпадает, «⚠ …» расходится, «не проверено» |
| Состояние | статус отправки и время |
| Текст / ошибка | причина ошибки; текст раскрывается по клику |

Действия в строке:
- **▶ Отправить сейчас** — для тестов: отправляет одну строку немедленно, мимо очереди, лимита и рабочих часов (с подтверждением);
- **✕** — исключить строку;
- **↺** — вернуть пропущенную или ошибочную строку в «новые».

Над таблицей — вкладки по состояниям и **⬇ Отчёт CSV**.

### Как отправляется
- **Человек** — личное сообщение.
- **Чат** — сообщение в группу; если указана тема форума, то в эту тему.
- Если ID чата в файле записан неверно (например, лишнее `-100`), панель попробует другой вариант записи, а затем поищет чат по названию среди ваших диалогов.

## Прогрев и лимиты

Настройки отправки: лимит в день и его рост, паузы между сообщениями, рабочие часы, стоп-слова, снятие паузы. Подробно — в [Прогрев и лимиты](limits.md).

## Журнал

Последние 500 событий: вход, импорт, завершение кампаний, ошибки, ограничения Telegram, отписки. Уровни: `info`, `warn` (оранжевый), `error` (красный).

## Статусы сообщений

| Статус | Значение |
|---|---|
| в очереди | ждёт отправки |
| доставлено | Telegram принял сообщение |
| прочитано | получатель открыл сообщение |
| ответил | получатель написал вам в личку после отправки |
| ошибка | не отправлено; причина в таблице — см. [Частые проблемы](troubleshooting.md) |
| пропущено | исключено вручную, отписался или нет текста |
| новая | только у списков xlsx: загружена, но не поставлена в очередь |

## Отписка и ответы

- Любой личный ответ переводит сообщения этому человеку в статус **«ответил»**.
- Если ответ **начинается со стоп-слова** («стоп», «stop», «отписаться», «unsubscribe», «не пишите» — список настраивается), контакт помечается отписавшимся. Все его сообщения в очередях получают статус «пропущено», и в будущие рассылки он не попадает.
