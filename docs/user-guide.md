## Роли

| | Админ | Менеджер |
|---|---|---|
| Свои аккаунты Telegram | ✓ | ✓ |
| Аккаунты других | видит и настраивает | — |
| Кампании | все | свои |
| Лиды | общая база | общая база |
| Команда, правила | ✓ | — |
| Вернуть отписавшегося, удалить лидов | ✓ | — |

Сменить свой пароль — клик по своему имени справа в меню. После смены пароля другие ваши входы завершаются.

## Дашборд

- **Аккаунты** — у каждого: отправлено сегодня / лимит, что сейчас делает отправка, сколько в очереди.
- **Воронка** — сколько лидов на каждом этапе.
- **Новые ответы** — последние входящие сообщения от лидов, со ссылкой «ответить» в инбокс.
- **Кампании** — сводка по последним 10.
- **↻ Обновить статусы прочтения** — запросить у Telegram прочтения. Панель делает это и сама раз в 30 минут, а пока она запущена, прочтения приходят мгновенно.
- **Последние события** — журнал.

## Инбокс и воронка

Вся переписка с лидами в одном месте. Счётчик рядом с «Инбокс» в меню — сколько диалогов с непрочитанными ответами.

**Слева — диалоги**, свежие сверху: имя, последнее сообщение («Вы: …» — если последним писали вы), этап, аккаунт. Зелёная точка — непрочитанный ответ. Фильтры: все / **ждут ответа** (последним написал человек) / непрочитанные, этап, сегмент, поиск; админу — «мои».

**Справа — переписка**: сообщения кампаний, ответы человека, ответы из панели и то, что менеджер написал этому лиду **прямо в Telegram**. Под сообщением — откуда оно (кампания «…», из панели, в Telegram) и кто отправил. Новые сообщения появляются сами, без перезагрузки.

- **Ответ** уходит от аккаунта, за которым закреплён лид; Ctrl+Enter — отправить. Писать можно только в уже начатую переписку: первое сообщение — через кампанию. Ответы не тратят дневной лимит рассылки, но при паузе аккаунта после ограничения Telegram не отправляются.
- **Этап воронки** — выпадающий список под перепиской; **заметка** — что важно помнить о человеке; **«Отписать»** — исключить из всех рассылок команды.
- В карточке: аккаунт, группа и дата вступления, сегменты, кампании, теги.
- Менеджер видит и отвечает только в диалоги своих аккаунтов; админ видит все.

### Воронка
По умолчанию: **написали → ответил → интерес → записался → пришёл / купил**, отдельно **отказ**.
- «написали» и «ответил» ставятся сами — при отправке из кампании и при первом ответе. Этап, поставленный вручную, автоматически не откатывается.
- Остальные этапы ставит менеджер в инбоксе.
- Этапы меняет админ в «Правилах»: переименовать, порядок, добавить, удалить (кроме двух автоматических), отметить «цель» и «отказ».
- Сводка по этапам — на дашборде и на странице сегмента.

## Кампании

Кампания — это лиды, текст и аккаунты, с которых писать.

### Два способа создать
- **По шаблону** — текст шаблона с переменными и спинтаксом, лиды из базы (все или по тегу).
- **Из списка xlsx** — у каждой строки свой готовый текст, ссылка на человека или чат, тема форума. Формат — [Формат списка xlsx](xlsx-format.md).

В обоих случаях выберите **аккаунты**, с которых писать. Менеджер выбирает из своих, админ — из любых.

### Найти получателей
Кнопка **🔎 «Найти получателей»** для каждого аккаунта кампании:
1. загружает все его диалоги (при тысячах — несколько минут, Telegram делает паузы);
2. сверяет «Историю общения» из файла с реальностью: есть ли личная переписка;
3. ищет людей по ID среди участников чатов кампании.

Если кампания идёт **с нескольких аккаунтов**, без этого шага людей в очередь поставить нельзя: только так понятно, кто из команды с кем знаком. Пока идёт поиск, аккаунты кампании не отправляют.

### Фильтр и очередь
Блок «Фильтр и очередь» раскрыт, пока очередь пуста. Фильтры: тип, диалог по файлу и по Telegram, «ты/вы», состояние, статус из файла, поиск.

- **➕ В очередь (N)** — поставить отфильтрованные строки в очередь;
- **➕ В очередь и запустить** — то же и сразу начать отправку.

При постановке в очередь каждый лид получает аккаунт — см. [Закрепление лидов](#закрепление-лидов). Строки, которые брать нельзя, получают статус «пропущено» с причиной: отписался, закреплён за чужим аккаунтом, команда писала ему недавно.

Порядок очереди: **чат → человек с диалогом → без диалога → снова чат…**

### Кнопки
- **▶ Запустить / ⏸ Пауза** — вся кампания.
- **Очистить очередь** — вернуть строки в «новые»; закрепление лидов сохраняется.
- **↻ Ошибки → в новые** — чтобы поставить их в очередь снова.
- **⬇ Отчёт CSV**, **Удалить** (переписка с лидами при этом сохраняется).
- **Изменить аккаунты кампании** — новые лиды будут распределяться между выбранными.

В строке: **▶** — отправить сейчас (мимо очереди, лимита и рабочих часов, но по правилам закрепления и отписки), **✕** — исключить, **↺** — вернуть в «новые».

## Сегменты

Сегмент — именованный список лидов, по которому потом создаётся кампания («Кампании» → «Кампания по шаблону» → выбрать сегмент). Сегменты общие для команды; один лид может быть в нескольких.

Как наполнить — на странице сегмента источники разложены по вкладкам (выбранная вкладка запоминается):
- **Из каналов TG** — участники группы: например, группы, куда вступают зарегистрированные на вебинар или семинар. Сначала «↻ Обновить список своих групп» (раз в какое-то время, при тысячах диалогов — пару минут), затем найдите группы поиском по названию и отметьте галочками — можно несколько сразу, «Выбрать все найденные» отмечает все группы, подходящие под поиск. Группы обрабатываются по очереди; если Telegram попросит подождать, загрузка остановится и покажет, какие группы не успела. В таблице видно число участников и аккаунт; ссылка **«открыть ↗»** открывает группу в веб-версии Telegram (нужно быть в ней под этим аккаунтом), **«в приложении»** — в Telegram Desktop или мобильном приложении, у публичных групп есть ещё ссылка `t.me/…`. Боты не добавляются. Повторная загрузка после следующего мероприятия добавит только новых участников. Для текста сохраняются `{group}` — название группы (если человек в нескольких — последней загруженной) и `{joined}` — дата вступления, например: `{first_name}, спасибо, что были на «{group}»!`
- **Из CSV** — те же колонки, что в «Лидах». Люди, которые уже есть в базе, не дублируются, а просто добавляются в сегмент.
- **Из контактов TG** — записная книжка или личные диалоги своего аккаунта. Эти лиды закрепляются за аккаунтом.
- **По тегу** — все лиды общей базы с выбранным тегом.

На странице видно: всего, **можно писать** (люди, не отписаны), **уже писали**, **отписаны**. Отписка и закрепление за аккаунтом действуют во всех сегментах.
**✕** в строке убирает лида из сегмента (из базы он не удаляется); убирать лидов, переименовывать и удалять сегмент может его автор или админ.

## Поиск групп

Раздел для поиска публичных групп Telegram по теме. Панель ничего не вступает — только находит и оценивает; вступаете вы сами по ссылке.

### Новый поиск по теме
- **Ключевые слова** — через запятую или с новой строки: «собственник», «бизнес клуб», «маркетинг».
- **География** (необязательно) — каждое слово ищется само по себе и в паре с каждым местом: «бизнес клуб», «бизнес клуб Минск»… Не больше 40 запросов на поиск.
- **Стоп-слова** (необязательно) — группы, у которых они есть в названии или описании, получают оценку 0.
- **Аккаунт**, от которого идёт поиск. Поиск идёт в фоне с паузами несколько минут; на это время отправка с аккаунта стоит. Ход виден в таблице «Поиски».

Что попадает в список: публичные группы из поиска Telegram и **группы обсуждения** найденных каналов. Сами каналы и закрытые группы без ссылки не попадают.

### Проверить ссылки
Вставьте список ссылок (`t.me/name`, `@name`, `t.me/+приглашение`, до 100) — например, из каталога tgstat.ru. Каналы пропускаются. По приглашению в закрытую группу видно только название и число участников.

### Оценка 0–100
| Часть | Вес | Как считается |
|---|---|---|
| Тема | 40 | сколько ключевых слов нашлось в названии, описании и последних 30 сообщениях (по основе слова: «предприниматель» находит «предпринимателей») |
| Живость | 35 | сообщений в день за последнюю неделю; 20 в день — максимум |
| Размер | 25 | число участников по логарифму; 10 000 — максимум |

Стоп-слово → 0. Последнее сообщение старше 30 дней → не выше 10.

### Работа со списком
- Вкладки: **в работе** (новые и интересные), новая, интересна, вступил, отклонена, все. Фильтры: поиск, название, минимальная оценка, сортировка.
- **★** — отметить интересной, **✕** — отклонить (больше не показывается в работе и не проверяется заново), **↺** — вернуть.
- **«вступил»** ставится само, когда группа появляется в диалогах аккаунта (после «Обновить список своих групп» в сегменте или после нового поиска); **«состою»** — метка у групп, где уже состоит ваш аккаунт.
- Ссылки у группы: `t.me/…` у публичных; у групп обсуждения без username — **«через канал t.me/…»** (откройте канал и нажмите «Комментарии»); «открыть ↗» (веб-версия) и «в приложении» — только для групп, где ваш аккаунт уже состоит: чужую группу по одному ID Telegram не открывает.
- Одна группа, найденная разными запросами, — одна строка; «запросов: N» показывает, сколькими.
- **↻** у поиска — повторить: добавит новые группы и обновит оценки тех, что проверялись больше недели назад.

## Лиды

Общая база команды: люди и чаты. Фильтр по сегменту показывает его состав.

- **Импорт из Telegram** — записная книжка или все личные диалоги выбранного аккаунта. Эти лиды сразу закрепляются за ним.
- **Импорт из CSV** — колонки `username`, `phone`, `user_id`, `first_name`, `last_name`, `tags`; любые другие станут переменными шаблона (`{company}`).
- Дубликаты по Telegram ID, username и телефону объединяются. Импорт **только дополняет** пустые поля и не переименовывает существующих лидов.
- Фильтры: поиск, тег, аккаунт («Мои лиды», «Ни за кем не закреплены»).
- **исключить** — отписать лида для всей команды. Вернуть может только админ.
- Удаление (админ) — только лиды без переписки.

## Шаблоны

| Возможность | Синтаксис | Результат |
|---|---|---|
| Переменные | `{first_name}`, `{last_name}`, `{name}`, `{username}`, `{phone}` + колонки CSV | данные лида |
| Спинтакс | `{Привет\|Добрый день\|Здравствуйте}` | у каждого получателя случайный вариант |
| Вложенность | `{Привет, {first_name}\|Добрый день}` | работает |
| Форматирование | `**жирный**`, `__курсив__`, `[текст](https://…)` | Markdown Telegram |

Кампания хранит свою копию текста: правка или удаление шаблона на идущие кампании не влияет.
**Тест в «Избранное»** отправляет пример в «Избранное» выбранного аккаунта.

## Аккаунты

Список аккаунтов: статус, отправлено сегодня / лимит, день прогрева, сколько лидов закреплено, что делает отправка.

- **⏸ / ▶** — остановить или возобновить отправку с аккаунта.
- **Настройки** — подпись, прогрев, лимит, паузы между сообщениями, рабочие часы, снятие паузы после ограничения. Подробно — [Прогрев и лимиты](limits.md).
- **Выйти** — завершить сессию панели в Telegram. Лиды и история остаются за аккаунтом; чтобы продолжить, войдите снова тем же аккаунтом.

Один Telegram-аккаунт можно подключить в панели только один раз.

## Команда и правила

**Команда** (админ): добавить человека, отключить, сменить пароль.

**Правила** (админ):
- **стоп-слова** — ответ, начинающийся с такого слова, отписывает лида от всех рассылок команды;
- **не писать одному человеку чаще раза в N дней** — из любых кампаний (чатов не касается).

## Журнал

События: входы, импорт, кампании, ограничения Telegram, отписки. Менеджер видит события своих аккаунтов и общие.

## Закрепление лидов

Лид закрепляется за аккаунтом при постановке в очередь (или при импорте из Telegram). Дальше:
- ему пишет только этот аккаунт — в любой кампании;
- если лид закреплён за аккаунтом, которого нет в кампании, он пропускается с пояснением;
- новые лиды достаются аккаунту, у которого **уже есть переписка** с человеком, иначе — наименее загруженному;
- ограничение Telegram на одном аккаунте **не** передаёт его лидов другим: они ждут, пока аккаунт восстановится.

## Статусы

| Статус | Значение |
|---|---|
| новая | в кампании, но не в очереди |
| в очереди | ждёт отправки со своего аккаунта |
| отправляется | отправка прямо сейчас |
| доставлено | Telegram принял сообщение |
| прочитано | получатель открыл сообщение |
| ответил | получатель написал этому аккаунту после отправки |
| ошибка | не отправлено; причина в строке — см. [Частые проблемы](troubleshooting.md) |
| пропущено | исключено: вручную, отписался, чужой лид, недавно писали, нет текста |

## Отписка и ответы

- Любой личный ответ сохраняется и переводит строки кампаний этого аккаунта в «ответил».
- Ответ, **начинающийся со стоп-слова целиком** («Стоп!», но не «стопудово»), отписывает лида **для всей команды**: его строки во всех очередях становятся «пропущено», в новые кампании он не попадёт.
