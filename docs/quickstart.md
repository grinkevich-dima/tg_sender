# Быстрый старт

## 1. Получите ключи API Telegram

1. Откройте https://my.telegram.org/apps и войдите по номеру телефона.
2. Создайте приложение:
   - **App title** — любое название;
   - **Short name** — от 5 до 32 латинских букв и цифр, например `sendertg2026`;
   - **URL** можно не заполнять;
   - **Platform** — Desktop.
3. Скопируйте **App api_id** (число) и **App api_hash** (32 символа).
   Блок «Available MTProto servers» с IP-адресами и публичными ключами не нужен.

> Если сайт отвечает просто «ERROR», отключите VPN или блокировщик рекламы либо попробуйте другой браузер.

## 2. Впишите ключи в `.env`

В папке проекта скопируйте `.env.example` в `.env` (файл скрытый; в Finder скрытые файлы показывает Cmd+Shift+.) и заполните его:

```ini
TG_API_ID=1234567
TG_API_HASH=0123456789abcdef0123456789abcdef
PANEL_PASSWORD=        # обязательно, если панель доступна не только с вашего компьютера
```

Значения пишутся без пробелов и кавычек. Никому не присылайте эти ключи.

## 3. Запустите панель

**Вариант А — Docker (рекомендуется):** дважды кликните `start.command`
или выполните в Терминале `docker compose up -d --build`.

**Вариант Б — без Docker:** `./run.sh` (создаст виртуальное окружение Python и запустит сервер).

Откройте **http://127.0.0.1:8000**.

## 4. Войдите в аккаунт

Проще всего войти **по QR-коду**:

1. В панели откройте «Войти» → **«📷 Войти по QR-коду»**.
2. На телефоне в **приложении Telegram** (не в обычной камере) откройте: Настройки → Устройства → **Подключить устройство**.
3. Наведите телефон на QR-код. Код обновляется сам каждые ~30 секунд.
4. Если включена двухэтапная проверка, панель попросит облачный пароль.

Можно войти и по коду: введите номер, нажмите «Получить код» **один раз** и ждите код в чате «Telegram» (с синей галочкой) на других ваших устройствах.

## 5. Первая рассылка

1. **Контакты** → «Импорт из Telegram» → «Записная книжка». Задайте тег, например `test`.
2. **Шаблоны** → напишите текст, например `{Привет|Добрый день}, {first_name}!` → нажмите **«Тест в „Избранное“»** и проверьте, как выглядит сообщение.
3. **Кампании** → выберите шаблон и тег → «Создать» (галочка «Запустить сразу»).
4. На **Дашборде** смотрите статус. Сообщения уходят по одному, с паузами.

Для первой пробы возьмите 3–5 человек, которые вас знают.
