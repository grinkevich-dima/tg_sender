# Быстрый старт

## 1. Получите ключи API Telegram

Ключи нужны один раз на всю команду.

1. Откройте https://my.telegram.org/apps и войдите по номеру телефона.
2. Создайте приложение:
   - **App title** — любое название;
   - **Short name** — от 5 до 32 латинских букв и цифр, например `sendertg2026`;
   - **URL** можно не заполнять;
   - **Platform** — Desktop.
3. Скопируйте **App api_id** (число) и **App api_hash** (32 символа).

> Если сайт отвечает просто «ERROR», отключите VPN или блокировщик рекламы либо попробуйте другой браузер.

## 2. Заполните `.env`

Скопируйте `.env.example` в `.env` (файл скрытый; в Finder скрытые файлы показывает Cmd+Shift+.) и заполните:

```ini
TG_API_ID=1234567
TG_API_HASH=0123456789abcdef0123456789abcdef
POSTGRES_PASSWORD=придумайте-длинный-пароль
```

Значения пишутся без пробелов и кавычек. Никому не присылайте эти ключи.

## 3. Запустите панель

Дважды кликните `start.command` или выполните в Терминале:

```bash
docker compose up -d --build
```

Откройте **http://127.0.0.1:8000**.

## 4. Создайте админа

При первом открытии панель попросит создать администратора: логин, имя, пароль (от 8 символов).

> Если панель раньше работала в однопользовательской версии, её аккаунт Telegram подключится к админу автоматически — входить заново не нужно.

## 5. Подключите аккаунт Telegram

1. **Аккаунты** → «Подключить аккаунт» → подпись, например «Дмитрий, продажи» → «Далее».
2. **«📷 Войти по QR-коду»**: на телефоне в **приложении Telegram** откройте Настройки → Устройства → **Подключить устройство** и наведите на QR.
3. Если включена двухэтапная проверка, введите облачный пароль.

## 6. Добавьте команду

**Команда** → логин, имя, пароль, роль «Менеджер». Каждый менеджер входит под своим логином и подключает **свой** аккаунт Telegram.

## 7. Первая кампания

1. **Шаблоны** → напишите текст, например `{Привет|Добрый день}, {first_name}!` → **«Тест в „Избранное“»**.
2. **Лиды** → «Импорт из Telegram» → «Записная книжка», тег `test`.
3. **Кампании** → «Кампания по шаблону»: шаблон, тег, свой аккаунт, «Запустить сразу».
4. На **Дашборде** видно, сколько ушло и кто ответил.

Для первой пробы возьмите 3–5 человек, которые вас знают.
